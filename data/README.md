# Data

This folder is for source documentation and small, openly licensed examples only. Do not commit raw or large datasets.

## Sources to investigate

- Crop production statistics: https://www.data.gov.in/resource/district-wise-season-wise-crop-production-statistics-1997
- Gujarat rainfall dataset listing: https://nwdp.nwic.gov.in/en/dataset/rainfall-gujarat-sw-gw-manual-daily

Verify current availability, download terms, field definitions, units, period coverage, and district naming/geographic level before use. Document access date and any transformations. Check whether the rainfall period is available early enough for the intended prediction; exclude features that would leak future information.

Local raw and processed data directories are ignored by Git.
